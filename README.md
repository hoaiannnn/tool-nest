# ToolNest — Nền tảng Công cụ Trực tuyến (Đồ án Lập trình Web - PTIT)

Dự án xây dựng hệ thống cung cấp các công cụ xử lý tệp, ảnh, văn bản trực tuyến.

## Tech Stack

- **Frontend:** React 18, TypeScript, Vite, Tailwind CSS, React Hook Form, Zod.
- **Backend:** Node.js, Express, TypeScript, Knex.js.
- **Database:** Microsoft SQL Server.
- **DevOps:** Docker, Docker Compose, GitHub Actions.

## Cấu trúc thư mục

- `/client`: Mã nguồn giao diện người dùng và trang quản trị (SPA).
- `/server`: Mã nguồn RESTful API, xử lý công cụ và kết nối cơ sở dữ liệu.
- `/docs`: Tài liệu thiết kế hệ thống (API Spec, giao diện mẫu).
